# 安全審計

## 概述
全面的安全審查，用於識別和修復程式碼庫中的漏洞。

## 步驟

### 1. 依賴項審計
- 檢查已知漏洞
- 更新過時的套件
- 審查第三方依賴項

### 2. 程式碼安全審查
- 檢查常見漏洞
- 審查身份驗證/授權
- 審計資料處理實踐

### 3. 敏感資料檢查
- [ ] config.ini 中的資料庫密碼是否安全
- [ ] service_account.json 是否已正確處理（不應提交到 Git）
- [ ] Line_Access_token.json 是否安全
- [ ] 是否有硬編碼的敏感資訊
- [ ] .gitignore 是否正確排除敏感檔案

### 4. 基礎設施安全
- 審查環境變數使用
- 檢查存取控制
- 審計網路安全（ERP 資料庫連線）

## 安全檢查清單
- [ ] 依賴項已更新且安全
- [ ] 無硬編碼密鑰
- [ ] 已實現輸入驗證
- [ ] 敏感檔案已正確處理
- [ ] 資料庫連線安全
