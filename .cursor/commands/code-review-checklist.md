# 程式碼審查清單

## 概述
用於進行全面程式碼審查的綜合清單，確保品質、安全性和可維護性。

## 審查類別

### 功能性
- [ ] 程式碼按預期功能執行
- [ ] 邊界情況得到處理
- [ ] 錯誤處理適當
- [ ] 無明顯錯誤或邏輯問題

### 程式碼品質
- [ ] 程式碼可讀且結構良好
- [ ] 函數小而專注
- [ ] 變數名具有描述性
- [ ] 無程式碼重複
- [ ] 遵循專案約定

### 安全性
- [ ] 無明顯安全漏洞
- [ ] 存在輸入驗證
- [ ] 敏感資料處理得當（如 config.ini、service_account.json）
- [ ] 無硬編碼密鑰

### Python 特定檢查
- [ ] 適當使用型別提示
- [ ] 異常處理完整
- [ ] 日誌記錄適當
- [ ] 無明顯效能問題

### 專案特定檢查（餅乾庫存算料系統）
- [ ] Google Sheets API 呼叫有適當的錯誤處理
- [ ] ERP 資料庫連線有適當的重試機制
- [ ] 日期解析和格式化正確（支援 YYYY/M/D 格式）
- [ ] 數字解析正確處理千分位逗號格式
- [ ] 庫存計算邏輯正確
