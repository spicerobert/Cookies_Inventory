# 檢查庫存計算邏輯

## 概述
專門用於檢查餅乾庫存算料系統的計算邏輯是否正確。

## 檢查項目

### 資料讀取
- [ ] 期初庫存從「實盤庫存」工作表正確讀取
- [ ] BOM 表資料完整且正確
- [ ] 生產排程資料正確（包含投料日期和生產片數）
- [ ] 組裝排程資料正確

### 計算邏輯
- [ ] 前置天數設定正確（預設 2 天）
- [ ] 完工入庫日期計算正確（投料日期 + 前置天數）
- [ ] 每日庫存計算公式正確：
  - 期末庫存 = 期初庫存 - 當天組裝需求 + 當天完工入庫
- [ ] 負庫存檢測正確
- [ ] 缺口數量計算正確

### 資料輸出
- [ ] 輸出到「庫存預估明細」工作表的格式正確
- [ ] 日期格式正確（YYYY/MM/DD）
- [ ] 數字格式正確（處理千分位逗號）
- [ ] 「是否負庫存」欄位正確顯示
- [ ] 「缺口數量」欄位正確計算

### 邊界情況
- [ ] 處理零庫存情況
- [ ] 處理負庫存情況
- [ ] 處理缺失資料情況
- [ ] 處理日期解析失敗情況
